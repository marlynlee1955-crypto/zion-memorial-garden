# Zion Memorial Garden - Cemetery Website

A clean, modern cemetery management website with user dashboard and plot reservation system.

## 📁 Project Structure

```
Gardenhtml/
├── index.html              # Main landing page
├── dashboard.html          # User dashboard
├── plot-details.html       # Plot details/grid view
│
├── components/             # HTML components
│   ├── header.html         # Navigation
│   ├── hero.html           # Hero section
│   ├── info-section.html   # Quick Access, Vision, Mission
│   ├── login-modal.html    # Login form
│   ├── register-modal.html # Registration form
│   └── ... (other components)
│
├── css/                    # Stylesheets
│   ├── main.css           # Global styles
│   ├── header.css         # Header styles
│   ├── dashboard.css      # Dashboard styles
│   └── ... (other styles)
│
├── js/                     # JavaScript files
│   ├── main.js            # Landing page logic
│   ├── login.js           # Login functionality
│   ├── dashboard.js       # Dashboard functionality
│   └── ... (other scripts)
│
└── assets/                 # Images and media
    ├── images/            # All images
    └── dashboard/         # Dashboard icons
```

## 🚀 How to Use

### **Open the Website**
1. Open `index.html` in your web browser
2. This is the main landing page

### **Edit Content**
- **Hero Title:** Edit `components/hero.html`
- **Quick Access:** Edit `components/info-section.html`
- **Navigation:** Edit `components/header.html`

### **Edit Styles**
- **Colors/Layout:** Edit files in `css/` folder
- **Main styles:** `css/main.css`

### **Edit Functionality**
- **Login:** `js/login.js`
- **Dashboard:** `js/dashboard.js`
- **Main page:** `js/main.js`

## 📝 Quick Edit Guide

| What to Change | File to Edit |
|----------------|--------------|
